## 2. 今回入った機能と Makefile オプション

`bin/Makefile` (GNU/Mac) と `bin/Makefile.xd_intel` の先頭に 3 つのスイッチ:

| 変数 | 既定 | 意味 |
|---|---|---|
| `OPENMP` | 0 | 1 で `-fopenmp` / `-qopenmp`。hydro/RT の godunov と cooling の sweep がスレッド化される |
| `BITREPRO` | 0 | 1 で `-ffp-contract=off` / `-fp-model strict`。**bit 比較をするときだけ**両方のビルドで 1 にする |
| (`COOLRATES_NOCACHE`) | 廃止 | 2026-11-11 に削除。cooling テーブル補間のキャッシュは呼び出し側の `coolrates_lookup` 引数になり TLS を使わない (TODO.md 2d-3) |

namelist (`&RUN_PARAMS`) に追加したもの:

- `omp_hydro`, `omp_rt`, `omp_cooling` (既定 .true.): 成分ごとにスレッド化を切る。競合の切り分けに使う。
- `timer_ranks_every` (既定 0): N coarse step ごとに `timer_ranks_<jobid>_n<step>.dat` を出す。
  ランごとの timer、level 別 grid/ghost/recv 数、粒子数、星数、SN 数、ホスト名の表。
- `cost_time_weighting`, `cost_time_relax`: 実測時間で load balance の重みを補正する試み。
  **本番で効果なし、`.false.` のまま** (TODO.md 2c)。
- 起動時に "Ranks i - j on <node>" を出す (どのノードを掴んだか)。

実行時の必須環境変数 (OPENMP=1 のとき): `OMP_STACKSIZE=64m` 以上 (`save` を外した作業配列が
スレッドのスタックに乗る。未設定だとワーカースレッドが溢れて落ちる。macOS では SIGBUS を RAMSES の
signal 10 ハンドラが拾って無限ループになるので注意)、`ulimit -s unlimited` (main スレッド用)。

## 3. テストの再現方法 (workstation)

Mac 側の作業ディレクトリ (`/private/tmp/claude-504/.../scratchpad`) は持っていかない。
以下で同じことができる。

1. 実行用の親ディレクトリに `dice/ UVB/ cloudy/ SED/` のシンボリックリンクを置く
   (データは Google Drive `マイドライブ/codes/ramses_data/`; CLAUDE.md テスト節)。
2. 参照ラン: `BITREPRO=1 OPENMP=0` で本番設定 (RT=1, NIONS=4, NGROUPS=7, DICE あり) をビルドし、
   `patch/takashi/tests/dice_rt_amr.nml` を `run.nml` にして 4 ランクで実行
   (Mac での参照ランは `star_as_nbody=.false.` に変えて使った。どちらでも可、揃えること)。
3. 試験ラン: `BITREPRO=1 OPENMP=1` でビルドし、`patch/takashi/tests/run_omp_cmp.sh` で実行+比較:

   ```
   patch/takashi/tests/run_omp_cmp.sh <bin_omp> <ref_dir> t1x1 1 4   # 1 スレッド: 参照と bit 一致のはず
   patch/takashi/tests/run_omp_cmp.sh <bin_omp> <ref_dir> t1x4 4 1   # 4 スレッド: 丸め誤差レベルの差
   ```

   期待値: 1 スレッドは 40〜48 ファイル全部一致。複数スレッドでは hydro の粗セル flux 補正の
   atomic の足す順で総和の相対差 ~1e-13 (`tests/hydro_stats.py` で比較)。
   cooling だけ (`omp_hydro=.false. omp_rt=.false.`) ならスレッド数によらず bit 一致。
4. 別ディレクトリでビルドするときは Makefile をコピーして `../` を絶対パスに置換 (CLAUDE.md)。

手元 Mac の到達点 (1 ランク、P コア 4 スレッド): hydro-godunov 3.2 倍、rt-godunov 3.4 倍、
cooling 3.7 倍、TOTAL 68.5 → 30.0 s。残りは未スレッド化部分 (poisson、粒子、refine、通信)。
