# sf_model=6 の速度分散 σ と α_vir の定義 (2026-11-24)

本番 (`hu_lv15_512x7`、dx = 3 pc) の `sf_model=6` (Kretschmer & Teyssier 2020、以下 KT20) で、星形成条件に入る σ が
何を測っているかを調べ、その結果を受けて 2 つのスイッチを足し、`sf_b_turb` の既定値を変えた。

## コードと KT20 の対応

- 効率の式は KT20 式 (18)、`s_crit` は式 (21) そのまま。KT20 には局所効率 ε も `1/φ_t` もない (遷音速コア内 100%)。
  `eps_star=1` が論文どおり。
- KT20 の σ は乱流エネルギー K の方程式の解 (生成項はトレースなしの対称ひずみだけ、収縮は乱流圧の仕事としてだけ効く)。
  コードの σ は 3×3×3 セルの質量加重の分散 (平均速度だけを引く) で、線形の速度勾配 (収縮・回転・シア) をすべて含む。
- α_vir の係数: 直径 ℓ の一様球で `15 (cs² + σ²) / (π G ρ ℓ²)`。KT20 は ℓ = Δx (係数 15/π)、コードは ℓ = 2 dx
  (係数 15/(4π) = 1.1937)。3×3×3 のセル中心は ±dx の範囲なので ℓ = 2 dx は σ を測るスケールと合っている。
  α_vir と Mach 数を同じ ℓ で定義していれば `s_crit` の形は変わらない。
- KT20 は `b` の値を書いていない。

## 調べたこと (output_00038、level 15 の nH > 10 のセル 92 万個)

27 セルの速度に線形の速度場を当てはめ、発散・シア・回転・残差に分けた。再現した星形成率は 10 Myr あたり 494 個
(実際の直近の値は 524 個)。星形成率で重みを付けた結果:

- 星形成率の 99.8% が `div v < 0` のセル、79% は 3 軸とも圧縮。
- `−div v / sqrt(4πGρ)` の中央値 1.3: 収縮率は自由落下程度。
- σ² の内訳 (体積加重の当てはめ): 収縮 0.39、シア 0.25、回転 0.21、残差 0.16。質量加重では収縮 0.76 (成分が直交せず
  交差項 −0.35)。
- 中心セルの密度は立方体平均の 2.5 倍 (中央値)。
- 実効の ε_ff は中央値 0.6% (10-90%: 0.09-1.8%)、α_vir 2.5、Mach 数 (1D) 3.7。

密度の高いガス全体 (星形成率で重みを付けない) ではシアと回転が 5-6 割で、収縮が支配的なのは星ができるセルだけ。
つまり重力収縮そのものを「乱流による支え」に数えていた。

## 足したもの (`&SF_PARAMS`、sf_model 6 と 7)

| 変数 | 既定 | 内容 |
|---|---|---|
| `sf_sigma_noconv` | `.false.` | σ² から等方的な収縮流を除く |
| `sf_alpha_meandens` | `.false.` | α_vir の ρ を中心セルではなく 27 セルの平均密度 (`dtot/27`) にする |
| `sf_b_turb` | 0.4√3 = 0.6928 (2026-11-24 までは 0.4) | `σ_s² = ln(1 + b² M²)` の b |

- `sf_sigma_noconv`: 立方体の重心まわりの動径流 `v − <v> = c (x − <x>)` を質量加重の最小二乗で当てはめ
  (`c = <(v−<v>)·(x−<x>)> / <|x−<x>|²>`)、`c < 0` のときだけ、それが説明する分散 `c² <|x−<x>|²>` を引く。1 変数の
  当てはめの残差なので負にならず、交差項も出ない。膨張 (`c > 0`) は残す。欠けた隣の代わりの father セルは名目の位置に置く。
- `sf_alpha_meandens`: 変えるのは α_vir の ρ だけ。Mach 数の `cs`、自由落下時間、セル質量は中心セルのまま。
- `sf_b_turb`: Federrath らの b (自然な混合で 0.4) は 3D の rms Mach 数に対する値。コードの Mach 数は `σ_1d/cs` なので
  √3 を掛けた。**既定値を変えたので、`sf_b_turb` を書いていない namelist は結果が変わる**。以前のランを再現するには
  `sf_b_turb=0.40000000596046448` (単精度の 0.4 を倍精度にした値) を書く。

## 効果の見積もり (output_00038 のガスの状態を固定した瞬間の星形成率、今の設定に対する比)

| 設定 | 比 | 星ができる nH (10/50/90%) | ε_ff (10/50/90%) |
|---|---|---|---|
| 今まで (b = 0.4) | 1 | 126 / 319 / 2130 | 0.09% / 0.6% / 1.8% |
| b = 0.693 だけ | 47 | 57 / 185 / 1300 | 1.5% / 8.5% / 21% |
| `sf_sigma_noconv` だけ | 10.8 | 155 / 1980 / 2480 | 1.5% / 25% / 62% |
| `sf_alpha_meandens` だけ | 0.12 | 113 / 255 / 562 | 0.01% / 0.08% / 0.2% |
| 2 つのスイッチ、b = 0.4 | 0.44 | 84 / 191 / 2130 | 0.05% / 0.5% / 3.9% |
| 2 つのスイッチ、b = 0.693 | 28 | 55 / 156 / 796 | 1.0% / 5.6% / 17% |

瞬間の値であって、流したときの星形成率ではない (星ができる密度が下がり、フィードバックのかかり方も変わる)。
b の効果がいちばん大きい。

## 確認

- 既定のスイッチ (b の既定値を変える前) で変更前のバイナリと bit 一致 (DICE RT 4 ランク 16 step、`sf_model=6`、
  `n_star=0.01`、40 ファイル)。
- 新しい σ と平均密度: 27 セルの入力を書き出す一時的な出力を入れ、独立に計算した値 (numpy の最小二乗) と比べて
  相対差 1e-13 (1564 セル、うち収縮を除いたもの 429)。father セルが入る箱はこの標本に無かった。
- 手元のテスト (levelmax 8、dx = 390 pc) では `sf_model=6` で星ができないので、星形成率への効果は本番の分解能でしか見られない。

## 限界

- FK12 のモデルは Mach 数 2 以下で破綻する (KT20 本文)。本番は 3-5、収縮を除くと 1-4 に下がる。
- 3×3×3 では格子スケールの乱流の圧縮モードと重力による落下を区別できない。
- 残った σ は数値粘性でならされた格子スケールの勾配で、セル以下の乱流の推定としては K の方程式を解くほうが筋が通る (未実装)。
